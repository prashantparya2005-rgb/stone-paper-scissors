## ✨ Features

- 🪨 Stone, Paper and Scissors options
- 🤖 Play against the computer
- 🎯 Random computer choice
- 🏆 Real-time score tracking
- ⚡ Instant game result
- 🔄 Replay functionality
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Select Stone, Paper, or Scissors.
2. The computer will randomly select its choice.
3. The game compares both choices.
4. The winner is displayed on the screen.
5. The score is updated automatically.

## 📋 Game Rules

| Player | Computer | Result |
|---|---|---|
| Stone | Scissors | Player Wins |
| Paper | Stone | Player Wins |
| Scissors | Paper | Player Wins |
| Same Choice | Same Choice | Draw |
